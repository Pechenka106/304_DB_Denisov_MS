# Лабораторная работа 1. Подготовка окружения для выполнения заданий и интерактивной работы с СУБД SQLite

### Cтруктура файлов данных:
- `ratings.csv` - csv-файл содержащий исходные данные об оценках фильмов userId|movieId|rating|timestamp
- `ratings.db` - db-файл с данными из файла `ratings.csv` для удобной работы в sqlite3
- `sqlite.txt` - txt-файл содержащий номер версии SQLite и режимы вывода данных, доступные в утилите sqlite3.
- `ratings_count.txt` - txt файл с min/max идентификатором пользователя из файла ratings.db и количеством строк с этими идентификатором.
