# Лабораторная работа №2. Подготовка скриптов для создания таблиц и добавления данных

## Описание

В рамках работы реализован процесс **ETL (Extract, Transform, Load)** для переноса исходных данных из текстовых CSV-файлов в базу данных SQLite.

Утилита на Python читает файлы из каталога `dataset/` и генерирует SQL-скрипт `db_init.sql`, содержащий:
- инструкции `DROP TABLE` (для удаления существующих таблиц);
- инструкции `CREATE TABLE` для создания структуры БД;
- инструкции `INSERT INTO` для загрузки данных.

Полученный скрипт выполняется утилитой `sqlite3`, в результате чего создаётся заполненная база данных `movies_rating.db`.

## Структура проекта

```
Task02/
├── README.md              # описание проекта
├── make_db_init.py        # утилита генерации SQL-скрипта
├── db_init.bat            # кроссплатформенный shell-скрипт запуска
├── db_init.sql            # генерируемый SQL-скрипт (появляется после запуска)
├── movies_rating.db       # результирующая база данных (появляется после запуска)
└── dataset/               # исходные данные 
    ├── genres.txt
    ├── movies.csv
    ├── occupation.txt
    ├── ratings.csv
    ├── tags.csv
    └── users.txt
```

## Требования к окружению

Для корректной работы скрипта `db_init.bat` на компьютере должны быть установлены:

| Компонент | Минимальная версия |
|-----------|--------------------|
| **Python** | 3.6+ |
| **SQLite3** | любая актуальная |
| **Bash** | любая (встроен в Linux/macOS; Git Bash для Windows) |
| **Git** | любая |

### Запуск ETL-процесса

```bash
./db_init.bat
```

Скрипт выполнит следующие шаги:
1. Запустит `make_db_init.py`, который сгенерирует `db_init.sql`.
2. Выполнит `sqlite3 movies_rating.db < db_init.sql`, создав и заполнив базу данных.

### Результат

После выполнения в каталоге `Task02/` появятся:
- `db_init.sql` — текстовый SQL-скрипт;
- `movies_rating.db` — заполненная база данных SQLite.
